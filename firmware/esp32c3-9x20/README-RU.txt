LED Matrix: две гирлянды
=======================
ПК v21; Android APK22 (2.3), интерфейс22.
Исходная ESP32 19x20: прошивка16 НЕ ИЗМЕНЕНА.
Новая ESP32-C3 Super Mini 9x20: прошивка17.

Обновите оба приложения через «Проверить обновления». Нажмите статус ONLINE/ПОИСК сверху и выберите нужную матрицу. Выбор локален для каждого приложения. Холст, картинки, сценарии и настройки хранятся раздельно для каждой модели. Холст между приложениями не синхронизируется; остальные общие данные синхронизируются напрямую по LAN для выбранной модели.

Первый запуск новой ESP32-C3
-------------------------
Первую установку сделайте по USB, не через старую гирлянду.
В Arduino IDE откройте LEDMatrixC3/LEDMatrixC3.ino.
Пакет плат: esp32 by Espressif Systems, проверено с3.3.12.
Библиотека: Adafruit NeoPixel, проверено с1.15.5.
Плата: ESP32C3 Dev Module (НЕ ESP32 Dev Module).
USB CDC On Boot: Enabled (обязательно: GPIO20/21 заняты лентами).
Flash Size: 4MB (сборка рассчитана на плату с4MB flash).
Partition Scheme: Default 4MB with spiffs (1.2MB APP/1.5MB SPIFFS).
Не выбирать No OTA или Huge APP: нужны два раздела OTA.
Питание светодиодов отдельно от5V подходящего блока; земля ESP и светодиодов общая. Не питать всю гирлянду от3.3V ESP.
Каждая из9 лент содержит20 светодиодов WS2812/GRB. Первый светодиод каждой ленты считается верхним.
Порядок лент слева направо: GPIO20,10,9,7,8,21,5,0,6.
GPIO8/9 — загрузочные пины: подключённая схема не должна принудительно менять их загрузочные уровни. Если плата не загружается, проверьте это аппаратно.
Внешняя кнопка сброса/забывания Wi-Fi не используется.

Без сохранённой сети плата создаёт точку Matrix-9x20, пароль12345678, адрес192.168.4.1. Подключитесь к ней, выберите профиль9x20 в приложении, в настройках задайте домашнюю сеть2.4GHz. Приложение и ESP затем должны находиться в одной локальной сети. Данные Wi-Fi сохраняются в ESP. При недоступной домашней сети предусмотрено возвращение точки доступа. Интернет для локального управления не нужен, для скачивания обновлений нужен.
Дальнейшие обновления C3 идут через «Проверить обновления» выбранного профиля9x20. Для C3 используется отдельный файл, не прошивка19x20.
Новые режимы в будущем потребуют отдельной сборки для каждой модели.

Возврат
-------
В меню выбора гирлянды можно отключить «Две гирлянды» и оставить одну19x20 без отката программы. Данные второй сохранятся.
Там же есть возврат к прежнему ПО: ПКv20 и интерфейсу телефонаv21. На телефоне APK22 остаётся, возвращается именно прежний интерфейс21; удалять приложение и его данные не нужно. Для прямой синхронизации откатывайте оба приложения вместе. Впоследствии обычная проверка обновлений вернёт новые версии.
Прошивка исходной ESP32 остаётся16, её откат не требуется.

Проверки
--------
Скомпилирована ESP32-C3 (1,230,195 байт программы в OTA-разделе1,310,720).
Собран APK с прежним сертификатом. Проверены переключение профилей, раздельные настройки/картинки/холст,12 режимов в обоих размерах, LAN-синхронизация, защита маршрутизации, миграция интерфейса и откат.
Тесты загрузчика проверяют обрыв потока, SHA-256, превышение размера и повторы.
Физическая плата пользователя и OTA на ней не проверялись: аппаратная проверка нужна после первой USB-установки. Гарантировать отсутствие всех ошибок без такой проверки нельзя.
