# LED Matrix — файлы обновлений

Здесь только готовые файлы, исходников нет.

- `version.json` — номера последних версий (их читают приложение и программа на ПК)
- `app/index.html` — интерфейс приложения (обновляется без переустановки)
- `app/LED-Matrix.apk` — приложение целиком
- `firmware/LEDMatrix.bin` — прошивка гирлянды (ставится по воздуху)
